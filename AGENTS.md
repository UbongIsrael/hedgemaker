# Frontend design skills

For frontend redesign work in this project, read and apply:

- `.agents/skills/redesign-existing-projects/SKILL.md`: audit the existing interface first and improve it within the existing stack while preserving functionality.
- `.agents/skills/design-taste-frontend/SKILL.md`: apply its contextual design guidance to landing pages, portfolios, and marketing surfaces, respecting its stated scope.

For product screens, dashboards, tables, and multi-step flows, use the redesign skill and the project's existing design patterns; the taste skill's marketing defaults do not apply automatically.

User instructions and existing project constraints take precedence. Resolve overlapping guidance in favor of the current brief, accessibility, and working behavior. Read the applicable skill before changing frontend code.

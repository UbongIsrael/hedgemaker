## Scope notes

Navigation can differ between current rendered homepages, older content templates and cached content fetches. The inventory is based on visible homepage menus. For example, Cloaked Guidebook appeared in fetched markup but not in the observed desktop Resources menu, so it is not counted as a visible navigation destination.

Unavailable visual coverage is an environment transport limitation, not a finding that the reference site itself is offline. Some fetched pages were cached from recent days. No precise animation durations, accessibility certification or performance scores were inferred from screenshots.
